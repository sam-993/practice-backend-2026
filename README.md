Sports Booking API
Система для управления бронированием спортивных площадок (теннисные корты, поля).

Функционал
Регистрация и JWT-авторизация.
Управление ресурсами (админ: создание/редактирование площадок).
Поиск свободных площадок и создание бронирований (клиент).

Технологический стек
Python (FastAPI)
PostgreSQL
SQLAlchemy
Docker & Docker Compose

Как запустить
Клонируйте репозиторий.
Создайте файл .env на основе .env.example.
Запустите проект: docker-compose up --build
Swagger API доступен по адресу: http://localhost:8000/docs
